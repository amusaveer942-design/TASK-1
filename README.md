# Data Science Internship – Data Cleaning & EDA

## Project Overview

This project was completed as part of my Data Science internship. It focuses on data cleaning, preprocessing, exploratory data analysis (EDA), and visualization using Python.

## Dataset

The dataset contains sales transaction information including:

* Transaction ID
* Date
* State
* City
* Category
* Product
* Quantity
* Unit Price
* Total Sales
* Customer Type
* Payment Method

The dataset intentionally contains missing values and duplicate records for practicing data-cleaning techniques.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Jupyter Notebook

## Data Cleaning

The notebook covers:

1. Loading the dataset
2. Understanding the dataset
3. Checking missing values
4. Handling missing values
5. Detecting duplicate values
6. Removing duplicate records
7. Detecting and handling outliers using IQR
8. Data visualization

## Exploratory Data Analysis

The project includes:

* Category distribution
* Histograms
* Line plots
* Scatter plots
* Sales analysis
* Quantity analysis

## Files

* CleaningData.ipynb – Complete data cleaning and EDA notebook
* data_science_internship_dataset_with_missing_duplicates.csv – Dataset used for analysis

## Outcome

The project demonstrates practical skills in data preprocessing, data cleaning, exploratory data analysis, and visualization using Python.
